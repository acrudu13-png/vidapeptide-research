# VidaPeptide Research — lab math tools for peptide research

> Free web tools and references for lyophilized research-peptide work: reconstitution math, COA reading, evidence tables. Built by [VidaPeptide](https://vidapeptide.eu/) (vidapeptide.eu) — a Romania-based store of batch-tested laboratory research peptides. All materials are sold strictly for laboratory research use; nothing here is medical or dosing advice.

## Tools

- **[Reconstitution calculator](https://acrudu13-png.github.io/vidapeptide-research/)** — concentration, draw volume, insulin-syringe units for any vial size, with community-reported aliquot presets per compound (BPC-157, TB-500, GHK-Cu, GLOW, KLOW, NAD+, glutathione, MOTS-c, Epithalon, Selank/Semax, Ipamorelin/CJC blends and more).
- Full bilingual version with the live catalog: https://vidapeptide.eu/en/calculator/ (EN) · https://vidapeptide.eu/calculator-reconstituire/ (RO)
